{% trans "What is a" %} {% trans "Root Canal?" %}

{% trans "A root canal (endodontic therapy) is a treatment used to repair and save a tooth that is badly decayed or infected. During the procedure, the nerve and pulp inside the tooth are removed, and the inside of the tooth is thoroughly cleaned and sealed." %}

{% trans "Why is it Needed?" %}

{% trans "Without treatment, the tissue surrounding the tooth will become heavily infected, and abscesses may form, leading to intense pain, facial swelling, and eventually, the loss of the tooth. A root canal entirely removes the source of the infection while allowing you to keep the structure of your natural tooth." %}

{% trans "Warning Signs" %}

{% trans "Signs You Need an RCT" %}

{% trans "If the nerve of your tooth is infected, you will likely experience one or more of these symptoms:" %}

  • {% trans "Severe Tooth Pain:" %} {% trans "Constant, throbbing ache, especially when biting or at night." %}
  • {% trans "Temperature Sensitivity:" %} {% trans "Lingering pain after eating hot or cold foods." %}
  • {% trans "Swollen Gums:" %} {% trans "Tender, swollen, or darkened gums near the painful tooth." %}
  • {% trans "Abscess (Pimple):" %} {% trans "A recurring pimple on the gums that may ooze pus." %}
  • {% trans "Tooth Discoloration:" %} {% trans "The tooth suddenly darkening from the inside out." %}
{% trans "The Root Cause" %}

{% trans "Common Causes" %}

{% trans "The pulp (nerve) of the tooth can become inflamed or infected due to several reasons:" %}

  • {% trans "Deep Tooth Decay:" %} {% trans "Untreated cavities that reach the inner pulp chamber." %}
  • {% trans "Cracked/Broken Tooth:" %} {% trans "Physical cracks allow bacteria to enter the nerve." %}
  • {% trans "Dental Trauma:" %} {% trans "A blow to the mouth can damage the nerve even without visible cracks." %}
  • {% trans "Repeated Procedures:" %} {% trans "Multiple deep fillings on the same tooth over time." %}
