{% trans "When is Extraction" %} {% trans "Required?" %}

{% trans "Reasons & Symptoms" %}

  • {% trans "Severe Decay:" %} {% trans "A cavity so deep that the tooth cannot be saved by a root canal." %}
  • {% trans "Advanced Gum Disease:" %} {% trans "Periodontitis has destroyed the bone supporting the tooth, making it loose." %}
  • {% trans "Orthodontic Crowding:" %} {% trans "Removing a tooth to create space for braces to align the remaining teeth." %}
  • {% trans "Impacted Wisdom Teeth:" %} {% trans "Third molars that are stuck under the gums, causing pain and infection." %}
  • {% trans "Severe Trauma:" %} {% trans "A tooth fractured below the gumline." %}

{% trans "Types of Extractions" %}

{% trans "Simple Extraction" %}

{% trans "Performed on a tooth that can be seen in the mouth. We loosen the tooth with an instrument called an elevator and remove it with dental forceps. It is very quick and requires only local anesthesia." %}

{% trans "Surgical Extraction" %}

{% trans "Required for a tooth that has broken off at the gum line or has not erupted yet (like a wisdom tooth). A small incision is made in the gum to access and carefully remove the tooth. Stitches may be placed afterward." %}

{% trans "Recovery & Aftercare" %}

{% blocktrans %}Proper aftercare is critical for a fast recovery and to prevent complications like 'dry socket'.{% endblocktrans %}

{% trans "Bite on Gauze" %}

{% trans "Keep steady pressure on the gauze pad for 30-45 minutes immediately after the procedure to allow the blood clot to form." %}

{% trans "Do NOT Spit or Use a Straw" %}

{% trans "For the first 24 hours, avoid aggressive rinsing, spitting, or drinking through a straw. The suction can dislodge the blood clot." %}

{% trans "Apply Ice" %}

{% trans "Apply an ice pack to your cheek in 15-minute intervals to minimize swelling, especially after a surgical extraction." %}

{% trans "Eat Soft Foods" %}

{% trans "Stick to soft foods (yogurt, soup, mashed potatoes) and avoid hot liquids on the first day." %}

{% trans "Frequently Asked Questions" %}

{% trans "We make sure you are completely numb before we begin. You will feel pressure during the procedure, but you should not feel any sharp pain. We also provide excellent pain management strategies for your recovery at home." %}

{% trans "A dry socket occurs if the blood clot that forms in the socket is dislodged prematurely, exposing the underlying bone and nerves. This is very painful. You can prevent it by not smoking, using straws, or spitting forcefully for the first few days." %}
