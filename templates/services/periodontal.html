{% trans "What is" %} {% trans "Gum Disease?" %}

{% trans "Periodontal disease (gum disease) is an infection of the tissues that hold your teeth in place. It is typically caused by poor brushing and flossing habits that allow plaque—a sticky film of bacteria—to build up on the teeth and harden." %}

{% trans "Gingivitis (Early Stage)" %}

{% trans "The mildest form of gum disease. Gums become red, swollen, and bleed easily. Fortunately, it is entirely reversible with professional treatment and good home care." %}

{% trans "Periodontitis (Advanced Stage)" %}

{% trans "If left untreated, gingivitis advances to periodontitis. The inner layer of the gum and bone pull away from the teeth and form pockets that collect debris and become infected, eventually leading to tooth loss." %}

{% trans "Watch For These" %}

Signs & Symptoms

{% trans "Gum disease can progress painlessly, producing few obvious signs, even in the late stages. However, watch out for:" %}

  • {% trans "Bleeding Gums:" %} {% trans "Especially during brushing or flossing." %}
  • {% trans "Swollen or Red Gums:" %} {% trans "Healthy gums should be firm and pale pink." %}
  • {% trans "Persistent Bad Breath:" %} {% trans "Caused by bacteria trapped in deep gum pockets." %}
  • {% trans "Gum Recession:" %} {% trans "Teeth look longer than they used to." %}
  • {% trans "Loose Teeth:" %} {% trans "Feeling wobbly or painful when chewing." %}
{% trans "The Root of the Problem" %}

Causes & Risk Factors

{% trans "While plaque is the primary cause, other factors can significantly increase your risk of developing severe gum disease." %}

  • {% trans "Poor Oral Hygiene:" %} {% trans "Inadequate brushing and flossing." %}
  • {% trans "Smoking:" %} {% trans "Interferes with the normal function of gum tissue cells." %}
  • {% trans "Diabetes:" %} {% trans "Higher risk of developing infections, including gum disease." %}
  • {% trans "Hormonal Changes:" %} {% trans "E.g., pregnancy can make gums more sensitive." %}
  • {% trans "Genetics:" %} {% trans "Some people are just more prone to severe gum disease." %}
{% trans "Disease Progression" %}

{% trans "Stages of" %} {% trans "Gum Disease" %}

{% trans "Catching gum disease early is critical to preventing irreversible bone and tooth loss." %}

{% trans "Healthy Gums" %}

{% trans "Firm, pale pink gums that fit snugly around the teeth. No bleeding during brushing or flossing." %}

{% trans "Gingivitis" %}

{% trans "Plaque irritates the gums, causing them to become red, tender, and swollen. Bleeding occurs during brushing. Reversible with professional scaling." %}

{% trans "Early Periodontitis" %}

{% trans "Inflammation reaches the bone. Gums begin pulling away from the teeth, forming pockets that trap bacteria. Minor bone loss begins." %}

{% trans "Advanced Periodontitis" %}

{% trans "Severe bone loss and deep gum pockets. Teeth become loose, shift out of place, and may need to be extracted to halt the infection." %}

{% trans "Solutions" %}

{% trans "Periodontal Treatments We Offer" %}

{% trans "Deep Cleaning" %}

{% trans "Subgingival scaling and root planing to remove tartar from deep below the gum line." %}

{% trans "Flap Surgery" %}

{% trans "For advanced cases. Gums are lifted back to remove deep tartar, then sutured tightly around the tooth." %}

{% trans "Splinting" %}

{% trans "A technique to stabilize loose teeth by attaching them to adjacent strong teeth." %}

{% trans "Bone Grafting" %}

{% trans "Rebuilding jawbone destroyed by periodontitis to save teeth or prepare for implants." %}
